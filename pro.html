Alumni Web Portal

Developed an Alumni Web Portal as a final-year project to manage and organize alumni information efficiently. The system serves as a database for old students, allowing easy access to their details and enabling networking among alumni and current students.
Features:
Alumni registration and profile management, Search and view alumni details, Networking and communication system, Event and announcement updates
Technologies Used:
Frontend: HTML, CSS
Backend: PHP
Database: MySQ
